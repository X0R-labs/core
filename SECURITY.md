# Security reporting

Do not publish credentials, private data or details of an unpatched exploitable vulnerability in an issue. Use a repository's **Security → Report a vulnerability** option if enabled. Otherwise contact the official [X0R Labs LinkedIn page](https://www.linkedin.com/company/x0r-labs/) to arrange a private reporting channel before sharing technical details.

Include the affected commit/version, reproduction steps using synthetic data, expected and actual behavior, and impact. Testing must stay within systems you own or are authorized to assess. We do not promise a response SLA or bounty.

Experimental projects are not certified security products. Consult project-specific security limitations before deploying sensitive workloads.
