# X0R Guard

X0R Guard checks tool calls against policy before your code runs them. It can also
sign and verify caller tokens. It uses only the Python standard library and requires
Python 3.11 or later.

Install with `pip install x0r-guard`. See the [SDK guide](https://github.com/X0R-labs/core/blob/main/docs/SDK.md)
for an example of wrapping an OpenAI-compatible client.
